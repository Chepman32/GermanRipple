# Native App Store screenshots

These are unaltered PNG screenshots captured from the working app by its passing Xcode UI tests on iOS 26.1. No promotional overlays, synthetic app data, resizing or image editing were used. The lesson completion and first-try score are real results of the test interaction.

| Directory | Simulator | Pixels | App Store draft |
|---|---|---|---|
| `iphone-6.3/` | iPhone 16 Pro | 1206 × 2622 | Five images in required medium Dynamic Island slot |
| `iphone-6.9/` | iPhone 16 Pro Max | 1320 × 2868 | Five images in optional large Dynamic Island slot |
| `ipad-13/` | iPad Pro 13-inch (M4) | 2064 × 2752 | Five images in required 13-inch slot |

Each set shows Today, a resolved lesson, Rules, Gallery and a completed-chain summary. Each manifest identifies the source test result and exported attachment, and retains a SHA-256 value for every image. The source `.xcresult` bundles are local ignored build artifacts.

All screenshots are saved to the English (US) draft for Apple app `6831985594`. This does not submit the app or establish editorial, accessibility or App Review approval. Final content changes require another screenshot review.
